# Knowledge

Knowledge from previous projects, kept to reuse in future ones.

General (no language or framework details):

- `DESIGN.md`: UI design rules
- `ARCHITECTURE.md`: system design
- `SECURITY.md`: safety and privacy
- `EXPERIENCE.md`: problems met and how they were solved (general and per platform)

One folder per language, with a file for the language and one per framework or tool in it:

- `css/CSS.md`
- `html/HTML.md`
- `python/PYTHON.md`, `python/UV.md`
- `rust/RUST.md`, `rust/DIOXUS.md`
- `shell/SHELL.md`

Each language or framework file uses the same sections as the general files (Design, Architecture, Security, Experience), leaving out the ones it has nothing for.
